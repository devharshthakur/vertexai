application.

## Available now

| Area             | Features                                                                      |
| ---------------- | ----------------------------------------------------------------------------- |
| Accounts         | Email/password sign-in, optional GitHub OAuth, student/instructor/admin roles |
| Courses          | Searchable catalog, course authoring, modules, lectures, admin approval       |
| Learning         | Enrollment, lecture progress, notes, bookmarks, streaks                       |
| Assessment       | Quizzes with automatic grading, assignments with manual grading               |
| AI               | Transcript-grounded tutor with citations, lecture summaries, quiz drafts      |
| Achievements     | Course certificates and milestone badges                                      |
| Instructor tools | Course analytics for lecture activity, progress, and quizzes                  |
| Demo             | Seeded accounts and courses; optional lecture videos                          |

## Planned

- AI study aids such as flashcards, study plans, and mastery scoring.
