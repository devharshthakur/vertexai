# Certificate fonts

The certificate PDF embeds Roboto Regular and Medium so names outside PDF's
standard ANSI font coverage render correctly.

- **Source:** Roboto files bundled with `pdfmake`.
- **License:** Apache License 2.0; see `LICENSE-Roboto.txt`.
- **Coverage:** Latin, Latin Extended, Greek, Cyrillic, and Vietnamese.

Additional fonts are needed for Devanagari, Arabic, Hebrew, and CJK scripts.
Nitro packages these files as server assets for use by the PDF renderer.
